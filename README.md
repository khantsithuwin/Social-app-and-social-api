# Social App and Social API

Monorepo for the social media full-stack project.

## Projects

- `social-app` — React + Vite frontend
- `social-api` — Express + Prisma backend

## Getting started

### API

```bash
cd social-api
npm install
npm run dev
```

Runs at `http://localhost:8800`.

### App

```bash
cd social-app
npm install
npm run dev
```
